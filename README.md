# Zero Brokerage

VortexCubes real-estate and commercial asset platform.

## Repository structure

* `apps/`: Client applications targeting end-users, brokers, agencies, and administrators.
* `backend/`: Server-side services and APIs powering platform operations.
* `packages/`: Shared internal packages and libraries reused across applications and backend services.
* `infrastructure/`: Infrastructure definitions, setup configurations, and deployment assets for external services and storage.
* `docs/`: Technical and architectural documentation, API contracts, schemas, architectural decision records, and development guidelines.
* `scripts/`: Development, build, maintenance, and automation scripts.

# API Service

## Purpose
Core API service and gateway entry point for the Zero Brokerage platform.

## Structure
* `src/app/`: Application bootstrap, lifecycle, and route registrations.
* `src/config/`: Service configuration and environment variables.
* `src/plugins/`: Fastify or server framework plugins and middlewares.
* `src/common/`: Common utilities, helpers, and shared service-level logic.
* `src/modules/`: Domain-specific API modules and controllers.
* `src/server.ts`: Server entrypoint.
